# Portfolio Website for Manish Solanki

This repository contains a responsive portfolio website scaffold designed for Netlify deployment.

## What is included

- `index.html` — responsive landing page with sections for about, skills, projects, experience, and contact
- `styles.css` — modern dark theme styling with responsive layout
- `script.js` — dynamic rendering for skills, projects, and experience cards

## Next steps

1. Open `script.js`.
2. Replace placeholder values in the `profile`, `skills`, `projects`, and `experience` arrays with your actual LinkedIn details.
3. Update your contact email and profile photo.
4. Push to Netlify or deploy using the Netlify CLI.

## Deploy to Netlify

1. Create a Git repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio"
   ```
2. Connect the repository to Netlify or drag-and-drop the repository folder into Netlify.
3. Set `index.html` as the publish file.

> Note: LinkedIn content could not be fetched automatically due to login restrictions, so please provide your exact skills, projects, and experience to finish the portfolio.
